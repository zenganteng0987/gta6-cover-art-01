Vice Poster — a GTA 6-style cover art maker. Build a multi-panel poster from your own photos (read on your own machine, never uploaded): three panel layouts (Vice Grid 5, Hero Strip 4, Nine Patch 9) in square, portrait and wide sizes, drag and zoom each photo inside its panel, four colour grades (Sunset, Neon, Dusk, Gold Hour) with a strength slider, bold caption lettering with a subtitle ribbon and star badge. Exports PNG at 1080x1080, 1080x1350 and 1920x1080. Fully static and offline; original design, no Rockstar assets or fonts.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
